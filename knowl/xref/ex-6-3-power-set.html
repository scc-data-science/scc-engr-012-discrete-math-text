Example 6.3.3.

Let \(X\) be a set with \(n\) elements. Find the cardinality of the power set of \(X\text{,}\) \(\mathcal{P}(X)\text{.}\)
🔗
Recall that \(\mathcal{P}(X)\) is the set of all subsets of \(X\text{.}\)
🔗
Solution.
You may recognize this question. It’s identical to Example 6.1.5. We’re revisitng this question here because it has a natural solutoin in terms of binomial coefficients.
🔗
Recall that \(\binom{n}{k}\) counts the number of ways to choose \(k\) unordered items from a set of \(n\) distinct total items. Said another way, \(\binom{n}{k}\) counts the number of \(k\) element subsets of a set of size \(n\text{.}\)
🔗
One way, then, to count the total number of subsets of a set of size \(n\) is to count all the subsets of size \(0\) – which is \(\binom{n}{0}\) – then all of the subsets of size \(1\) – which is \(\binom{n}{1}\) – then all of the subsets of size \(2\) – which is \(\binom{n}{2}\) – and so on until you reach the subsets of size \(n\) – which is \(\binom{n}{n}\text{.}\) So,
\begin{equation*} \lvert \mathcal{P}(X) \rvert = \sum_{k=0}^n \binom{n}{k}. \end{equation*}
