Definition 7.7.2.

Let \(x_1, x_2, \ldots, x_n\) be the support of a random variable \(X\text{.}\) Then, the expected value of \(X\text{,}\) denoted by \(\mathbb{E}[X]\text{,}\) is defined by:
\begin{equation*} \mathbb{E}[X] = \sum_{k=1}^n x_k \cdot \mathbb{P}(X = x_k). \end{equation*}
