Example 8.2.1.

Let \(a_0, a_1, a_2, \ldots\) be the sequence defined recursively as follows. Let:
\begin{equation*} a_k = a_{k - 1} + 2 \end{equation*}
for \(k \geq 1\) together with the initial condition \(a_0 = 1\text{.}\) Use iteration to deduce an explicit formula for the sequence.
🔗
Hint.
Start by writing \(a_1\text{,}\) then substitute \(a_1\) into the expression for \(a_2\text{.}\) Repeat this process for as many \(a_k\) as you need until you start to notice a pattern.
🔗
Try leaving each term unsimplified.
🔗
🔗
Solution.
Let’s write out the first few terms of the sequence.
\begin{align*} a_0 \amp = 1, \\ a_1 \amp = a_0 + 2 = 1 + 2 = 3, \\ a_2 \amp = a_1 + 2 = 3 + 2 = 5, \\ a_3 \amp = a_2 + 2 = 5 + 2 = 7. \end{align*}
Do you notice a pattern? The terms seem to be the odd positive integers. Therefore, a natural guess would be that:
\begin{equation*} a_k = 2k + 1. \end{equation*}
Indeed, \(a_3 = 2 \cdot 3 + 1 = 7\text{,}\) as expected, so our formula seems to be doing the right thing.
