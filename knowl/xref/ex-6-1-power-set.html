Example 6.1.5.

Let \(X\) be a set with \(n\) elements. Find the cardinality of the power set of \(X\text{,}\) \(\mathcal{P}(X)\text{.}\)
🔗
Recall that \(\mathcal{P}(X)\) is the set of all subsets of \(X\text{.}\)
🔗
Solution.
To specify a given element \(S\) of \(\mathcal{P}(X)\text{,}\) we need to decide whether each element of \(X\) is included in \(S\text{.}\)
🔗
Suppose \(X = \{x_1, x_2, \ldots, x_n\}\text{.}\) Let \(E_i\) denote the event that \(x_i \in S\text{.}\) Then, for each \(i = 1, 2, \ldots, n\text{,}\) there are two outcomes for \(E_i\) (either \(x_i \in S\) or \(x_i \not\in S\)), and so \(\lvert E_i \rvert = 2\text{.}\) So, by Theorem 6.1.1 there are:
\begin{equation*} \lvert E_1 \rvert \cdot \lvert E_2 \rvert \cdot \cdots \cdot \lvert E_n \rvert = \underbrace{2 \cdot 2 \cdot \cdots \cdot 2}_{n \text{ copies}} = 2^{n} \end{equation*}
ways to select \(S\text{,}\) and so \(\lvert \mathcal{P}(X) \rvert = 2^{n}\text{.}\)
