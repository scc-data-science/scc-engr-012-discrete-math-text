Definition 5.1.1.

If \(d\) and \(n\) are integers with \(d \neq 0\text{,}\) we say that \(d\) divides \(n\) if there exists an integer \(k\) such that \(n = kd\text{.}\) That is, \(d\) divides \(n\) if \(n / d\) is an integer. If \(d\) divides \(n\text{,}\) we write \(d \mid n\text{.}\)
🔗
In this context, \(d\) is called the divisor and \(n\) is called the multiple or sometimes the dividend.
