Theorem 5.1.6.

Let \(a\text{,}\) \(b\text{,}\) and \(c\) be integers with \(a \neq 0\text{.}\) Then:
🔗
  1. If \(a \mid b\) and \(a \mid c\text{,}\) then \(a \mid (b + c)\text{.}\)
    🔗
    🔗
  2. If \(a \mid b\text{,}\) then \(a \mid bc\) for any integer \(c\text{.}\)
    🔗
    🔗
  3. If \(a \mid b\) and \(b \mid c\text{,}\) then \(a \mid c\text{.}\)
    🔗
    🔗
🔗
🔗

Proof.

Let \(a\text{,}\) \(b\text{,}\) and \(c\) be integers with \(a \neq 0\text{.}\)
🔗
  1. Suppose \(a \mid b\) and \(a \mid c\text{.}\) Then there exists integers \(k\) and \(\ell\) such that \(b = ka\) and \(c = \ell a\text{.}\) Then,
    \begin{equation*} b + c = ka + \ell a = (k + \ell) a, \end{equation*}
    and so \(a \mid (b + c)\text{.}\)
    🔗
    🔗
  2. Suppose \(a \mid b\text{.}\) Then there exists an integer \(k\) such that \(b = ka\text{.}\) Then,
    \begin{equation*} bc = (ka)c = (kc)a, \end{equation*}
    and so \(a \mid bc\text{.}\)
    🔗
    🔗
  3. Left as an exercise.
    🔗
    🔗
