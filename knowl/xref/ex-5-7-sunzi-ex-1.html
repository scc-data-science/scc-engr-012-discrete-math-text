Example 5.7.1.

Suppose:
🔗
\begin{align*} x \amp \equiv 2 \pmod 3 \\ x \amp \equiv 3 \pmod 7 \end{align*}
🔗
What is \(x\text{?}\)
🔗
Solution.
Perhaps the best thing to do right now is to just list out all the values of \(x\) that satisfy both congruences.
🔗
\begin{align*} x \amp \equiv 2 \pmod 3 \implies x \in \{\ldots, 2, 5, 8, 11, 14, 17, \ldots \} \\ x \amp \equiv 3 \pmod 7 \implies x \in \{\ldots, 3, 10, 17, \ldots \} \end{align*}
🔗
So, it looks like \(17\) is a solution.
🔗
There is a better way. Instead, we turn the first congruence back into an equation and write \(x = 2 + 3k\) for some integer \(k\text{.}\) Then, we substitute this back into the second congruence:
🔗
\begin{align*} x \equiv 3 \pmod 7 \amp \implies 2 + 3k \equiv 3 \pmod 7\\ \amp \implies 3k \equiv 1 \pmod 7 \end{align*}
🔗
This is now a familiar problem! We know this can be solved, provided \(3^{-1}\) exists modulo \(7\text{.}\) Since \(\mathrm{gcd}(3, 7) = 1\text{,}\) an inverse does indeed exists. Here, \(k \equiv 3^{-1} (1) \equiv 5 \pmod 7\text{.}\)
🔗
Finally, this gives \(x = 2 + 3k = 2 + 3(5) = 17\text{.}\)
🔗
In fact, all solutions to the system are of the form \(x \equiv 17 \pmod{3 \cdot 7 = 21}\text{.}\) We’ll motivate why this is true in the homework.
