Example 5.4.5.

Find the remainder when \(2718\) is divided by \(9\text{.}\)
🔗
Solution.
Note that you could just use the division algorithm. These numbers are not large, so it would not take too much time. However, to illustrate the utility of Theorem 5.4.4, we’ll use modular arithmetic.
🔗
Note that we can write exlicitly the decimal expansion of \(2718\text{:}\)
🔗
\begin{equation*} 2718 = 2 \cdot 10^3 + 7 \cdot 10^2 + 1 \cdot 10^1 + 8. \end{equation*}
🔗
Now, to find the remainder upon division by \(9\text{,}\) we need to find \(2719 \text{ mod } 9\text{.}\) That is, we need to find \(x\) such that \(x \equiv 2718 \, (\text{mod } 9)\text{.}\) The reason the decimal expansion is useful here is because \(10 \equiv 1 \, (\text{mod } 9)\text{.}\) Moreover, from Theorem 5.4.4, \(10^n \equiv 1^n \equiv 1 \, (\text{mod } 9)\) for any positive integer \(n\text{.}\) So:
🔗
\begin{align*} x \amp \equiv 2718 \amp (\text{mod } 9) \\ \amp \equiv 2 \cdot 10^3 + 7 \cdot 10^2 + 1 \cdot 10^1 + 8 \amp (\text{mod } 9) \\ \amp \equiv 2 \cdot 1^3 + 7 \cdot 1^2 + 1 \cdot 1^1 + 8 \amp (\text{mod } 9) \\ \amp \equiv 2 + 7 + 1 + 8 \amp (\text{mod } 9) \\ \amp \equiv 18 \amp (\text{mod } 9) \\ \amp \equiv 0 \amp (\text{mod } 9) \end{align*}
🔗
It turns out, \(2718\) is divisible by \(9\text{.}\)
