Theorem 5.3.6.

Let \(a\) and \(b\) be integers that are not both zero. Then \(d = \mathrm{gcd}(a, b)\) exists and is unique.
🔗
🔗

Proof.

Consider the set \(S\) of all integer linear combinations of \(a\) and \(b\text{:}\)
🔗
\begin{equation*} S = \{ ax + by \mid x, y \in \mathbb{Z} \}. \end{equation*}
🔗
Note that \(S\) contains at least one positive element, since it contains the integers \(a\text{,}\) \(-a\text{,}\) \(b\text{,}\) and \(-b\text{.}\) Let \(d\) be the smallest positive element in \(S\text{.}\) We claim that \(d = \mathrm{gcd}(a, b)\text{.}\)
🔗
By definition, \(d \in S\) implies \(d = ax_0 + by_0\) for some integers \(x_0\) and \(y_0\text{.}\) In order to show that \(d = \mathrm{gcd}(a, b)\text{,}\) we need to verify Properties 1, 2, and 3 of Definition 5.3.5. We know that \(d \gt 0\) by definition, so Property 1 is satisfied. If any other integer \(e\text{,}\) if \(e \mid a\) and \(e \mid b\text{,}\) then \(e \mid d\) by Theorem 5.1.6, so Property 3 is satisfied. To show that \(d \mid a\text{,}\) we use the division algorithm (Theorem 5.3.1) to write:
🔗
\begin{equation*} a = qd + r, \end{equation*}
🔗
where \(0 \leq r \lt d\text{.}\) Our goal therefore reduces to showing that \(r = 0\text{.}\) Indeed,
🔗
\begin{equation*} r = a - qd = a - q(ax_0 + by_0) = a(1 - qx_0) + b(-qy_0). \end{equation*}
🔗
Thus, \(r \in S\text{.}\) But this is a contradiction, since we assumed \(d\) was the smallest positive element in \(S\) and we know \(0 \leq r \lt d\text{.}\) Thus, by contradiciton, we conclude \(r = 0\) and therefore \(d \mid a\text{.}\) The proof that \(d \mid b\) is identical. Thus, Property 2 is satisfied, and we conclude \(d = \mathrm{gcd}(a, b)\text{.}\)
