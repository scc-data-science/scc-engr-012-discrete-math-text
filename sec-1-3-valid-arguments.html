    Section 1.3 Valid and Invalid Arguments

    Subsection 1.3.1 Valid Arguments

    In this lecture, we’ll discuss how to use the work we’ve been doing to determine whether or not arguments are logically valid or invalid; i.e., whether or not the truth of the conclusion necessarily follows from the truth of the hypotheses.
    🔗

    Definition 1.3.1.

    An argument is a sequence of statements.
    🔗
    🔗

    Definition 1.3.2.

    All statements in an argument, except for the final one, are called premises (or assumptions or hypotheses). The final statement is called the conclusion.
    🔗
    🔗

    Definition 1.3.3.

    An argument is valid if the following is true: For any choice of statements substituted for the statement variables in the argument’s premises, if the resulting premises are all true, then the conclusion is also true.
    🔗
    🔗

    Example 1.3.4. Modus Ponens.

    The following argument is valid:
    🔗
    \begin{align*} \begin{aligned} \amp p \implies q \\ \amp p \\ \hline \therefore \amp q \end{aligned} \end{align*}
    🔗
    Solution.
    We can prove this using a truth table:
    🔗
    \(p\) \(q\) \(p \implies q\)
    \(T\) \(T\) \(T\)
    \(T\) \(F\) \(F\)
    \(F\) \(T\) \(T\)
    \(F\) \(F\) \(T\)
    • The premise “\(p \implies q\)” is true in rows 1, 3, and 4.
      🔗
    • The premise “\(p\)” is true in rows 1 and 2.
      🔗
    • Thus, the premises are all true only in row 1.
      🔗
    • The conclusion “\(q\)” is true only in row 1.
      🔗
    • Hence, all rows in which the premises are true, the conclusion is also true, and so the argument is valid.
      🔗
    🔗
    🔗
    🔗

    Example 1.3.5. Modus Tollens.

    The following argument is valid:
    🔗
    \begin{align*} \begin{aligned} \amp p \implies q \\ \amp \lnot q \\ \hline \therefore \amp \lnot p \end{aligned} \end{align*}
    🔗
    Solution.
    Prove this!
    🔗
    🔗
    🔗

    Example 1.3.6.

    Show that the following argument is valid.
    🔗
    \begin{align*} \begin{aligned} \amp p \implies q \\ \amp \lnot p \implies q \\ \hline \therefore \amp q \end{aligned} \end{align*}
    🔗
    Solution.
    Again, we do this using a truth table:
    🔗
    \(p\) \(q\) \(p \implies q\) \(\lnot p\) \(\lnot p \implies q\)
    \(T\) \(T\) \(T\) \(F\) \(T\)
    \(T\) \(F\) \(F\) \(F\) \(T\)
    \(F\) \(T\) \(T\) \(T\) \(T\)
    \(F\) \(F\) \(T\) \(T\) \(F\)
    • The premise “\(p \implies q\)” is true in rows 1, 3, and 4.
      🔗
    • The premise \(\lnot p \implies q\) is true in rows 1, 2, and 3.
      🔗
    • Thus, the premises are all true only in rows 1 and 3.
      🔗
    • The conclusion is true only in rows 1 and 3.
      🔗
    • Hence, all rows in which the premises are true, the conclusion is also true, and so the argument is valid.
      🔗
    🔗
    🔗
    🔗
    Arguments that are valid are also called rules of inference. Other rules of inference include:
    🔗
    • Generalization:
      🔗
      \begin{align*} \begin{aligned} \amp p \\ \hline \therefore \amp p \lor q \end{aligned} \end{align*}
      🔗
      🔗
    • Specialization:
      🔗
      \begin{align*} \begin{aligned} \amp p \land q \\ \hline \therefore \amp p \end{aligned} \end{align*}
      🔗
      🔗
    • Elimination:
      🔗
      \begin{align*} \begin{aligned} \amp p \lor q \\ \amp \lnot p \\ \hline \therefore \amp q \end{aligned} \end{align*}
      🔗
      🔗
    • Transitivity:
      🔗
      \begin{align*} \begin{aligned} \amp p \implies q \\ \amp q \implies r \\ \hline \therefore \amp p \implies r \end{aligned} \end{align*}
      🔗
      🔗
    • Proof by Division Into Cases:
      🔗
      \begin{align*} \begin{aligned} \amp p \implies r \\ \amp q \implies r \\ \amp p \lor q \\ \hline \therefore \amp r \end{aligned} \end{align*}
      🔗
      🔗
    🔗
    🔗

    Subsection 1.3.2 Invalid Arguments

    Definition 1.3.7.

    An argument that is not valid is called an invalid argument.
    🔗
    🔗

    Definition 1.3.8.

    Errors in logic that produce invalid arguments are called logical fallacies.
    🔗
    🔗
    We noted in the previous sections that contrapositives are logically equivalent to their corresponding conditional statements, but that converses and inveres are not. Using the converse or the inverse in an argument produces a logical fallacy.
    🔗

    Example 1.3.9. Converse Error.

    The following argument is invalid:
    🔗
    \begin{align*} \begin{aligned} \amp p \implies q \\ \amp q \\ \hline \therefore \amp p \end{aligned} \end{align*}
    🔗
    Solution.
    You can prove that this is invalid by drawing a truth table and finding at least one row for which the premises are both true and the conclusion is not. It is also fairly easy to see intiuitively that this argument is invalid by producing an example that is clearly false by choosing \(p\) and \(q\) judiciously. For example,
    🔗
    If I love all branches of math, then I will love discrete mathematics.
    🔗
    I love discrete mathematics.
    🔗
    Therefore, I love all branches of math.
    🔗
    🔗
    It is fairly easy to imagine a scenario in which someone loves discrete mathematics but does not like, say, differential equations. A computer scientist, for example, whose career replies on discrete objects might feel this way.
    🔗
    🔗
    🔗

    Example 1.3.10. Inverse Error.

    The following argument is invalid:
    🔗
    \begin{align*} \begin{aligned} \amp p \implies q \\ \amp \lnot p \\ \hline \therefore \amp \lnot q \end{aligned} \end{align*}
    🔗
    Solution.
    Try to come up with a particular example that gives intuitive justification for the fact that this is a fallacy!
    🔗
    🔗
    🔗
    🔗

    Subsection 1.3.3 Sound vs Unsound Arguments

    We’ve defined valid arguments via conditionals: an argument is valid if all premises being true implies the conclusion is true. This leaves room for an argument that is valid, but has false premises. In such cases, it is not possible to know, from the structure of the argument alone, if the argument is valid, since knowledge about the truth values of the premises is necessary.
    🔗
    In order to be sure that the conclusion of an argument is true regardless of the particular realizations of the premises, we need a more specific notion of “validity.”
    🔗

    Definition 1.3.11.

    An argument is called sound if, and only if, it is valid and all its premises are true.
    🔗
    🔗

    Definition 1.3.12.

    An argument that is not sound is called unsound.
    🔗
