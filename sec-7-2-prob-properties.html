    Section 7.2 Basic Properties of Probability Theory

    Probability measures have several desirable properties, which can be derived directly from the axioms, Theorem 7.1.3
    🔗

    Theorem 7.2.1.

    Suppose \(\mathbb{P}\) is a probability measure on \(\Omega\) and that \(A\text{,}\) \(B\text{,}\) and \(C\) are events. Then:
    1. \(\mathbb{P}(\varnothing) = 0\text{.}\)
      🔗
      🔗
    2. If \(A \subseteq B\) then \(\mathbb{P}(A) \leq \mathbb{P}(B)\text{.}\)
      🔗
      🔗
    3. \(\mathbb{P}(A \cup B) = \mathbb{P}(A) + \mathbb{P}(B) - \mathbb{P}(A \cap B)\text{.}\)
      🔗
      🔗
    4. \(\mathbb{P}(A \cup B) \leq \mathbb{P}(A) + \mathbb{P}(B)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    1. Notice that \(\Omega = \Omega \cup \varnothing\text{,}\) where \(\Omega \cap \varnothing = \varnothing\text{.}\) So, by the additivity and normalization axioms of Axiom 7.1.2, we have:
      \begin{equation*} 1 = \mathbb{P}(\Omega) = \mathbb{P}(\Omega \cup \varnothing) = \mathbb{P}(\Omega) + \mathbb{P}(\varnothing). \end{equation*}
      Since \(\mathbb{P}(\Omega) = 1\text{,}\) we conclude \(\mathbb{P}(\varnothing) = 0\text{.}\)
      🔗
      🔗
    2. Write \(B = A \cup (B \smallsetminus A)\text{.}\) Since the sets are disjoint, we can use the additivity axiom of Axiom 7.1.2 to write:
      \begin{equation*} \mathbb{P}(B) = \mathbb{P}(A \cup (B \smallsetminus A)) = \mathbb{P}(A) + \mathbb{P}(B \smallsetminus A). \end{equation*}
      Now, from the nonnegativity axiom, we have \(\mathbb{P}(B \smallsetminus A) > 0\text{,}\) and so \(\mathbb{P}(B) \geq \mathbb{P}(A)\text{.}\)
      🔗
      🔗
    3. Left as an exercise.
      🔗
      🔗
    4. Left as an exercise.
      🔗
      🔗
    🔗
    🔗

    Example 7.2.2 Inclusion-Exclusion for Two Events: Divisibility.

    A number is chosen uniformly at random from \(\{1, 2, \dots, 100\}\text{.}\) Find the probability that it is divisible by \(2\) or by \(3\text{.}\)
    🔗
    Solution.
    Let \(\Omega = \{1, 2, \dots, 100\}\text{,}\) and let \(A\) be the event that the number is divisible by \(2\) and \(B\) the event that it is divisible by \(3\text{.}\) We want \(\mathbb{P}(A \cup B)\text{.}\) Counting multiples gives
    \begin{align*} \mathbb{P}(A) \amp = \frac{\lfloor 100/2 \rfloor}{100} = \frac{50}{100},\\ \mathbb{P}(B) \amp = \frac{\lfloor 100/3 \rfloor}{100} = \frac{33}{100}. \end{align*}
    The event \(A \cap B\) is the event that the number is divisible by both \(2\) and \(3\text{,}\) that is, by \(6\text{,}\) so
    \begin{equation*} \mathbb{P}(A \cap B) = \frac{\lfloor 100/6 \rfloor}{100} = \frac{16}{100}. \end{equation*}
    By part (3) of Theorem 7.2.1,
    \begin{equation*} \mathbb{P}(A \cup B) = \frac{50}{100} + \frac{33}{100} - \frac{16}{100} = \frac{67}{100}. \end{equation*}
    🔗
    Note that simply adding \(\mathbb{P}(A) + \mathbb{P}(B) = \frac{83}{100}\) would overcount: the \(16\) multiples of \(6\) are counted once in each event, so they must be subtracted once.
    🔗
    🔗
    🔗

    Example 7.2.3 The Union Bound: Reliability of a System.

    A server runs three independent hardware components. Over one year, the probability that the disk fails is at most \(0.02\text{,}\) the probability that the power supply fails is at most \(0.01\text{,}\) and the probability that the network card fails is at most \(0.03\text{.}\) Give an upper bound on the probability that at least one component fails during the year.
    🔗
    Solution.
    Let \(D\text{,}\) \(P\text{,}\) and \(N\) be the events that the disk, power supply, and network card fail, respectively. We want to bound \(\mathbb{P}(D \cup P \cup N)\text{.}\) We do not need to know how the failures are related to each other, which is the point of using the union bound.
    🔗
    Apply part (4) of Theorem 7.2.1 to the events \(D \cup P\) and \(N\text{:}\)
    \begin{equation*} \mathbb{P}(D \cup P \cup N) \leq \mathbb{P}(D \cup P) + \mathbb{P}(N). \end{equation*}
    Applying part (4) again to \(D\) and \(P\) gives \(\mathbb{P}(D \cup P) \leq \mathbb{P}(D) + \mathbb{P}(P)\text{,}\) so
    \begin{equation*} \mathbb{P}(D \cup P \cup N) \leq \mathbb{P}(D) + \mathbb{P}(P) + \mathbb{P}(N) \leq 0.02 + 0.01 + 0.03 = 0.06. \end{equation*}
    Thus the probability that some component fails is at most \(6\%\text{.}\)
    🔗
    This bound holds regardless of whether the failures are independent, disjoint, or strongly correlated, so it is useful when the dependence between events is unknown. It is generally not exact: if the failures can occur together, the true probability is smaller, by the correction term in part (3).
    🔗
    🔗
    🔗

    Example 7.2.4 Monotonicity: Bounding a Hard Probability by an Easy One.

    Five fair coins are flipped. Let \(E\) be the event that the number of heads is \(3\) or more and the first coin is heads. Show that \(\mathbb{P}(E) \leq \frac{1}{2}\text{,}\) and then find \(\mathbb{P}(E)\) exactly.
    🔗
    Solution.
    Let \(\Omega\) be the set of all \(2^5 = 32\) equally likely sequences of heads and tails, and let \(F\) be the event that the first coin is heads. Every outcome in \(E\) has first coin heads, so \(E \subseteq F\text{.}\) Since \(F\) fixes the first coin and leaves the other four free, \(|F| = 2^4 = 16\) and \(\mathbb{P}(F) = \frac{16}{32} = \frac{1}{2}\text{.}\) By part (2) of Theorem 7.2.1,
    \begin{equation*} \mathbb{P}(E) \leq \mathbb{P}(F) = \frac{1}{2}. \end{equation*}
    This bound required no counting beyond the event \(F\text{.}\)
    🔗
    For the exact value, an outcome in \(E\) has first coin heads and at least \(2\) heads among the remaining four coins. The number of such sequences is
    \begin{equation*} \binom{4}{2} + \binom{4}{3} + \binom{4}{4} = 6 + 4 + 1 = 11, \end{equation*}
    so \(\mathbb{P}(E) = \frac{11}{32}\text{.}\) This is consistent with the bound, since \(\frac{11}{32} \leq \frac{16}{32}\text{.}\)
    🔗
    🔗
    🔗

    Example 7.2.5 Finding an Unknown Probability and Checking a Model.

    In a certain town, \(60\%\) of households own a dog, \(45\%\) own a cat, and \(20\%\) own neither. A household is chosen at random.
    1. What is the probability that the household owns both a dog and a cat?
      🔗
      🔗
    2. A neighbor claims that \(70\%\) of households own a dog and \(40\%\) own a cat, and that \(25\%\) own both. Is this claim consistent with the laws of probability?
      🔗
      🔗
    🔗
    Solution.
    1. Let \(D\) be the event that the household owns a dog and \(C\) the event that it owns a cat. The event that the household owns neither is the complement of \(D \cup C\text{,}\) so
      \begin{equation*} \mathbb{P}(D \cup C) = 1 - 0.20 = 0.80. \end{equation*}
      Solving part (3) of Theorem 7.2.1 for the intersection gives
      \begin{equation*} \mathbb{P}(D \cap C) = \mathbb{P}(D) + \mathbb{P}(C) - \mathbb{P}(D \cup C) = 0.60 + 0.45 - 0.80 = 0.25. \end{equation*}
      So \(25\%\) of households own both.
      🔗
      🔗
    2. The claimed values would give
      \begin{equation*} \mathbb{P}(D \cup C) = 0.70 + 0.40 - 0.25 = 0.85, \end{equation*}
      which is not itself a contradiction. However, the claim says \(D \cap C\) has probability \(0.25\) while \(C\) has probability \(0.40\text{,}\) and we can check the consistency conditions: since \(D \cap C \subseteq C\text{,}\) part (2) requires \(\mathbb{P}(D \cap C) \leq \mathbb{P}(C)\text{,}\) and indeed \(0.25 \leq 0.40\text{.}\) Similarly \(D \cap C \subseteq D\) gives \(0.25 \leq 0.70\text{.}\) Finally, part (4) requires \(\mathbb{P}(D \cup C) \leq \mathbb{P}(D) + \mathbb{P}(C) = 1.10\text{,}\) which holds. All of the checks pass, so the claim is consistent with the laws of probability. (It would be inconsistent if, for example, the neighbor had claimed that \(50\%\) own a cat and dog, since then \(\mathbb{P}(D \cap C) = 0.50 > \mathbb{P}(C) = 0.40\) would violate part (2).)
      🔗
      🔗
    🔗
    🔗
    🔗
    You might be wondering if there is an analog to part 3 of Theorem 7.2.1 for three (or more) sets. It turns out, there is, but it is remarkably uglier.
    🔗

    Theorem 7.2.6 The Principle of Inclusion-Exclusion.

    Suppose \(\mathbb{P}\) is a probability measure on \(\Omega\) and that \(A\text{,}\) \(B\text{,}\) and \(C\) are events. Then:
    \begin{align*} \mathbb{P}(A \cup B \cup C) \; = \; \amp \mathbb{P}(A) + \mathbb{P}(B) + \mathbb{P}(C)\\ \amp \quad - [\mathbb{P}(A \cap B) + \mathbb{P}(A \cap C) + \mathbb{P}(B \cap C)]\\ \amp \quad + \mathbb{P}(A \cap B \cap C) \end{align*}
    🔗
    🔗

    Proof.

    One of the most useful tactics for proving probability theorems is to consider samples as subsets of \(\Omega\) and utilizing what we know from set theory. With this, we imagine adding these components together one at a time. Refer to Figure 7.2.7.
    🔗
    First, we compute \(\mathbb{P}(A) + \mathbb{P}(B) + \mathbb{P}(C)\text{.}\) Notice, however, this counts the intersections more than once, so we need to subtract the intersections, \(\mathbb{P}(A \cap B)\text{,}\) \(\mathbb{P}(A \cap C)\text{,}\) and \(\mathbb{P}(B \cap C)\text{.}\)
    🔗
    However, after we subtract the intersections of each pair, we’ve subtracted the inner most region, \(\mathbb{P}(A \cap B \cap C)\) three times, we we have to add it back.
