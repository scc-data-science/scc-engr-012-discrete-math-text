    Section 7.6 Random Variables

    Let’s consider the experiment of flipping a fair coin three times, wherein we assume the tosses are independent. Suppose we are interested in keeping track of how many times we see a heads in this experiment. Let \(X\) denote that number of heads. Then,
    \begin{equation*} X \in \{0, 1, 2, 3\}. \end{equation*}
    Let’s compute the probability of measuring \(X = k\) heads for all possible values of \(k\text{.}\) Notice that, regardless of \(k\text{,}\) there are \(2^3 = 8\) possible outcomes of this experiment, since there are three coin tosses and only two possible outcomes per toss. So:
    🔗
    1. If \(k = 0\text{,}\) then we have no heads in our list, hence we have \(\mathbb{P}(X = 0) = \frac{1}{8}\text{.}\)
      🔗
      🔗
    2. If \(k = 1\text{,}\) then we need to count the number of ways to distribute one head among three coins. There are \(\binom{3}{1} = 3\) ways to do this, so we have \(\mathbb{P}(X = 1) = \frac{3}{8}\text{.}\)
      🔗
      🔗
    3. If \(k = 2\text{,}\) then we need to count the number of ways to distribute two heads among three coins. There are \(\binom{3}{2} = 3\) ways to do this, so we have \(\mathbb{P}(X = 2) = \frac{3}{8}\text{.}\)
      🔗
      🔗
    4. If \(k = 3\text{,}\) then all three tosses are heads, hence we have \(\mathbb{P}(X = 3) = \frac{1}{8}\text{.}\)
      🔗
      🔗
    🔗
    In total, we find:
    \begin{align*} \mathbb{P}(X = 0) \amp = \frac{1}{8} \\ \mathbb{P}(X = 1) \amp = \frac{3}{8} \\ \mathbb{P}(X = 2) \amp = \frac{3}{8} \\ \mathbb{P}(X = 3) \amp = \frac{1}{8} \end{align*}
    🔗
    When we enumerate all possible realizations of such an \(X\) and compute their individual probabilities, the result is called the distribution of that experiment. When we treat the outcome of an experiment as a variable (like we did here with \(X\)), we call it a random variable. Let’s define these terms more formally below.
    🔗

    Definition 7.6.1.

    A random variable is a numerical variable that represents the outcome of an experiment. More formally, it is a function that assigns a real number to each outcome of an experiment.
    🔗
    🔗
    Below are some examples of random variables.
    🔗

    Example 7.6.2 Rolling Two Dice.

    Suppose we roll two fair six-sided dice. The sample space consists of 36 ordered pairs \(\omega = (d_{1}, d_{2})\text{.}\) Defining \(X = d_{1} + d_{2}\) gives us a random variable with support \(\{2, 3, 4, \ldots, 12\}\text{.}\)
    🔗
    🔗

    Example 7.6.3 Counting Packet Loss.

    A batch of \(n\) data packets is transmitted over a noisy channel, where each packet fails independently with probability \(p\text{.}\) Let \(X\) be the number of corrupted packets. This gives us a random variable with finite support: \(\{0, 1, 2, \ldots, n\}\text{.}\)
    🔗
    🔗

    Example 7.6.4 Web Scraping.

    A web scraper repeatedly pings an API until it receives a valid 200 OK response. Let \(X\) be the total number of attempts required. Because the scraper could theoretically fail arbitrarily many times before succeeding, this gives us a random variable for which the support is countably infinite: \(\{1, 2, 3, \ldots \}\text{.}\)
    🔗
    🔗
    Next, we formalize the notion of a distribution.
    🔗

    Definition 7.6.5.

    A discrete probability distribution is the set of all values of a discrete random variable, together with the corresponding probability. More accurately, a discrete probability distribution can be represented as the following set:
    \begin{equation*} \left\{ \left( x, \mathbb{P}(X = x) \right) \mid x \in \mathrm{Support}(X) \right\}. \end{equation*}
    🔗
    🔗
    While Definition 7.6.5 is formally correct, it is almost never what people mean when they talk about distributions. When we speak of distributions, we’re usually referring to the histogram of the distribution: one bar for each value \(x\) in the support, whose height is \(\mathbb{P}(X = x)\text{.}\) Figure 7.6.6 shows the histogram for the number of heads in three fair coin tosses. Notice that the bar heights sum to \(1\text{.}\)
    🔗
    For comparison, Figure 7.6.7 shows the distribution of the sum of two fair dice from Example 7.6.2. There are \(36\) equally likely outcomes, and the sum \(x\) can be obtained in \(6 - |x - 7|\) of them, so \(\mathbb{P}(X = x) = \frac{6 - |x - 7|}{36}\text{.}\) Unlike the coin example, the most likely value sits in the middle, at \(x = 7\text{,}\) and the probabilities fall off linearly on either side.
    🔗
    We’ll talk more about how to summarize these distributions in the next section.
