    Section 5.7 Sunzi’s Theorem

    In the previous section, we discussed how we might solve some linear congruences. In this section, we concern ourselves with systems of linear congruences. That is, can we find a procedure to find solutions to:
    🔗
    \begin{align*} x \equiv \amp \; a_1 \pmod{m_1}\\ x \equiv \amp \; a_2 \pmod{m_2}\\ \vdots \amp \; \\ x \equiv \amp \; a_k \pmod{m_k} \end{align*}
    🔗
    It turns out, like many of our results in number theory, a solution exists provided that the moduli \(m_1, \ldots, m_k\) are pairwise coprime.
    🔗

    Subsection 5.7.1 Sunzi’s Theorem

    We start with a motivating example.
    🔗

    Example 5.7.1.

    Suppose:
    🔗
    \begin{align*} x \amp \equiv 2 \pmod 3 \\ x \amp \equiv 3 \pmod 7 \end{align*}
    🔗
    What is \(x\text{?}\)
    🔗
    Solution.
    Perhaps the best thing to do right now is to just list out all the values of \(x\) that satisfy both congruences.
    🔗
    \begin{align*} x \amp \equiv 2 \pmod 3 \implies x \in \{\ldots, 2, 5, 8, 11, 14, 17, \ldots \} \\ x \amp \equiv 3 \pmod 7 \implies x \in \{\ldots, 3, 10, 17, \ldots \} \end{align*}
    🔗
    So, it looks like \(17\) is a solution.
    🔗
    There is a better way. Instead, we turn the first congruence back into an equation and write \(x = 2 + 3k\) for some integer \(k\text{.}\) Then, we substitute this back into the second congruence:
    🔗
    \begin{align*} x \equiv 3 \pmod 7 \amp \implies 2 + 3k \equiv 3 \pmod 7\\ \amp \implies 3k \equiv 1 \pmod 7 \end{align*}
    🔗
    This is now a familiar problem! We know this can be solved, provided \(3^{-1}\) exists modulo \(7\text{.}\) Since \(\mathrm{gcd}(3, 7) = 1\text{,}\) an inverse does indeed exists. Here, \(k \equiv 3^{-1} (1) \equiv 5 \pmod 7\text{.}\)
    🔗
    Finally, this gives \(x = 2 + 3k = 2 + 3(5) = 17\text{.}\)
    🔗
    In fact, all solutions to the system are of the form \(x \equiv 17 \pmod{3 \cdot 7 = 21}\text{.}\) We’ll motivate why this is true in the homework.
    🔗
    🔗
    🔗
    The key idea was that we could write one of the congruences as an equation and substitute that equation into the other congruence. This provides us with a linear congruence that we can solve, in theory, using the methods outlined in Section 5.6. We can naturally extend this idea to more moduli.
    🔗

    Example 5.7.2.

    Suppose:
    🔗
    \begin{align*} x \amp \equiv 2 \pmod{3} \\ x \amp \equiv 3 \pmod{7} \\ x \amp \equiv 4 \pmod{16} \end{align*}
    🔗
    What is \(x\text{?}\)
    🔗
    Solution.
    We can use the result of Example 5.7.1 on the first two congruences. The first two congruences imply \(x \equiv 17 \pmod{3 \cdot 7 = 21}\text{.}\)
    🔗
    From this, our set of three congruences reduces to a set of two:
    🔗
    \begin{align*} x \amp \equiv 17 \pmod{21} \\ x \amp \equiv 4 \pmod{16} \end{align*}
    🔗
    Now, we can solve these two new congruences using exactly the same process. Try it! The answer is \(x \equiv 164 \pmod{3 \cdot 7 \cdot 16 = 336}\text{.}\)
    🔗
    🔗
    🔗
    We can further extend this process, naturally, to arbitrarily many moduli. The key assumption is that each pair of moduli, \(m_i\) and \(m_j\text{,}\) satisfy \(\mathrm{gcd}(m_i, m_j) = 1\text{.}\) If this process holds for any pair of moduli, we say that \(m_1, \ldots, m_k\) are pairwise coprime.
    🔗

    Theorem 5.7.3 Sunzi’s Theorem.

    Let \(m_1, m_2, \ldots, m_k \geq 2\) be pairwise coprime. Suppose \(a_1, a_2, \ldots, a_k \in \mathbb{Z}\text{.}\) Then:
    🔗
    \begin{align*} x \equiv \amp \; a_1 \pmod{m_1}\\ x \equiv \amp \; a_2 \pmod{m_2}\\ \vdots \amp \; \\ x \equiv \amp \; a_k \pmod{m_k} \end{align*}
    🔗
    1. Has a solution.
      🔗
      🔗
    2. If \(x\) and \(y\) are both solutions, then \(x \equiv y \pmod{\prod_{j=1}^k m_j}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    In most (Western) mathematical literature, Theorem 5.7.3 is called the Chinese remainder theorem. I take some issue with this name. Generally in math, we like to celebrate the people that make great discoveries, which is why we have names like “the Pythagorean Theorem” or “Euler’s identntiy.” However, if the discoverers are not Euro-American, the mathematical community tends to over-generalize and name such discoveries after broad geographic, linguistic, or cultural groups. This theorem was first studied by the Chinese mathematician Sunzi in the mathematical treatise Sunzi Suanjing somewhere between the 3rd and 5th centuries CE.
    🔗
    The proof of Theorem 5.7.3 relies on the ideas presented in the examples above.
    🔗
    1. We can start by solving the first two congruences in the same way we did in Example 5.7.1. This will give us a new congruence modulo \(m_1m_2\text{.}\)
      🔗
      🔗
    2. Solve your new congruence modulo \(m_1m_2\) together with the third congruence in the same way we did in Example 5.7.2.
      🔗
      🔗
    3. Repeat this process inductively until you’ve exhausted all congruences.
      🔗
      🔗
