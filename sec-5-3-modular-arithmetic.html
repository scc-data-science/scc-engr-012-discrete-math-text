    Section 5.4 Modular Arithmetic

    In the last section, we remaked that, for a fixed integer \(d\text{,}\) the function \(f: \mathbb{Z} \to \{0, 1, \ldots, d\}\) such that \(f(n) = n \text{ mod } d\) generates a partition of the integers. We make this idea formal here.
    🔗

    Subsection 5.4.1 Residue Classes Modulo \(m\)

    We’ll illustrate this using an example. Consider the function \(f : \mathbb{Z} \to \{0, 1, 2\}\) given by \(f(n) = n \text{ mod } 3\text{.}\) Then, following Theorem 5.3.1 closely, notice that:
    🔗
    \begin{align*} f^{-1}(0) \amp = \{ \ldots, -6, -3, 0, 3, 6, \ldots \}, \\ f^{-1}(1) \amp = \{ \ldots, -5, -2, 1, 4, 7, \ldots \}, \\ f^{-1}(2) \amp = \{ \ldots, -4, -1, 2, 5, 8, \ldots \}. \end{align*}
    🔗
    We see that \(f^{-1}(0) \cup f^{-1}(1) \cup f^{-1}(2) = \mathbb{Z}\) and that \(f^{-1}(k) \cap f^{-1}(j) = \varnothing\) for any \(k \neq j\text{.}\) As we saw in Homework 4, this implies that division by 3 partitions the integers into nonoverlapping sets. We call these sets residue classes modulo 3.
    🔗
    Since all of the numbers in a given residue class “behave” the same way under \(f\text{,}\) we might consider each of these numbers to be “equivalent” in some sense. For example, since \(1 \text{ mod } 3 = 7 \text{ mod } 3\text{,}\) \(1\) and \(7\) are the same up to division by \(3\text{.}\) We capture this equivalence with the following definition.
    🔗

    Definition 5.4.1.

    If \(a\) and \(b\) are integers and \(m\) is a positive integer, then \(a\) is congruent to \(b\) modulo \(m\) if \(m \mid a - b\text{.}\) If \(a\) is congruent to \(b\) modulo \(m\text{,}\) we write \(a \equiv b \; (\text{mod } m)\text{.}\)
    🔗
    🔗

    Example 5.4.2.

    Determine whether
    🔗
    1. \(22\) is congruent to \(7\) modulo \(5\text{.}\)
      🔗
      🔗
    2. \(24\) is congruent to \(14\) module \(6\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. Since \(5\) divides \(22 - 7 = 15\text{,}\) we have \(22 \equiv 7 \, (\text{mod } 5)\text{.}\)
      🔗
      🔗
    2. Since \(6\) does not divide \(24 - 14 = 10\text{,}\) we have \(24 \not\equiv 14 \, (\text{mod } 5)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗
    Definition 5.4.1 tells us how to map between the world of congruences and the world of equations. Being able quickly code switch between the two is an important skill in number theory.
    🔗

    Theorem 5.4.3.

    Let \(a\) and \(b\) be integers and \(m\) be a positive integer. Then \(a\) is congruent to \(b\) modulo \(m\) if any only if there exists an integer \(k\) such that \(a = b + km\text{.}\)
    🔗
    🔗

    Proof.

    🔗
    \((\implies)\) Suppose \(a \equiv b \, (\text{mod }m)\text{.}\) Then \(m \mid a - b\text{,}\) and so there exists an integer \(k\) such that \(a - b = km\text{.}\) Therefore, \(a = b + km\text{.}\)
    🔗
    \((\impliedby)\) Suppose \(a = b + km\) for some integer \(k\text{.}\) Then equivalently \(a - b = km\text{,}\) and hence \(m \mid a - b\text{.}\) Hence, \(a \equiv b \, (\text{mod }m)\text{.}\)
    🔗
